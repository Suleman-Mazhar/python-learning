# __python-learning__

A personal repository documenting my journey learning Python — from fundamentals to more advanced topics.

## About

This repo is a collection of scripts, exercises, and mini-projects I'm working through as I build my Python skills. It serves as both a learning log and a reference I can come back to.

## Topics Covered

- Variables, data types & operators
- Control flow (if/else, loops)
- Functions & scope
- Data structures (lists, dicts, tuples, sets)
- File I/O
- OOP (classes, inheritance)
- Error handling
- Modules & packages
- Working with APIs
- Scripting & automation

## How It's Organised

Each folder or file corresponds to a topic or exercise. Comments are included throughout to explain what's going on and what I learned.
